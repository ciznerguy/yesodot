סוגי פעולות: מדריך מקוצר

יסודות מדעי המחשב, שפת #C. ארבעה סוגי פעולות, איך מזהים כל סוג בשאלה, ודוגמה קצרה להרצה.

את הפעולות כותבים בתוך class Program, מחוץ ל-Main, ואת הקריאות כותבים בתוך Main.

1לא מקבלת ולא מחזירה

בשאלה: "יש לכתוב פעולה המדפיסה שורה של 10 כוכביות"
static void PrintStars()
{
    for (int i = 1; i <= 10; i++)
    {
        Console.Write("*");
    }
    Console.WriteLine();
}
קריאה מ-Main ופלט
PrintStars();
**********

2מקבלת פרמטרים ומדפיסה

בשאלה: "יש לכתוב פעולה המקבלת שני מספרים ומדפיסה את סכומם"
static void PrintSum(int a, int b)
{
    Console.WriteLine("Sum: " + (a + b));
}
קריאה מ-Main ופלט
PrintSum(3, 4);
Sum: 7

3לא מקבלת, אבל מחזירה

בשאלה: "יש לכתוב פעולה הקולטת מספר חיובי ומחזירה אותו"
static int ReadPositive()
{
    Console.Write("Enter a positive number: ");
    int num = int.Parse(Console.ReadLine());
    while (num <= 0)
    {
        Console.Write("Error. Enter a positive number: ");
        num = int.Parse(Console.ReadLine());
    }
    return num;
}
קריאה מ-Main ופלט
int n = ReadPositive();
Console.WriteLine("You entered " + n);
Enter a positive number: -3
Error. Enter a positive number: 8
You entered 8

4מקבלת ומחזירה

בשאלה: "יש לכתוב פעולה המקבלת שני מספרים ומחזירה את הגדול מביניהם"
static int Max(int a, int b)
{
    if (a > b)
    {
        return a;
    }
    return b;
}
קריאה מ-Main ופלט
int big = Max(4, 9);
Console.WriteLine("The bigger is " + big);
The bigger is 9
לרוב לא מדפיסה. את הערך המוחזר שומרים במשתנה או מדפיסים ב-Main.
