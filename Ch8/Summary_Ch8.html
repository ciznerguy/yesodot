85מהי מחרוזת, והשמה בין מחרוזות

גם רווח וסימן פיסוק הם תווים. מחרוזת ריקה "" היא מחרוזת בלי תווים בכלל. מדפיסים את המחרוזת בין שני קווים, כדי לראות בדיוק איפה היא מתחילה ונגמרת.

string s1 = "Hello World!";
string s2 = "H";
string s3 = "";

string a = "lion";
string b = "dog";
a = b;
a = "cat";

שימו לב: אחרי a = b שני המשתנים שווים ל-"dog". השמה חדשה ל-a לא משנה את b.

88מעבר על מחרוזת: ספירת מילים

סופרים את הרווחים במשפט. בין כל שתי מילים יש רווח אחד, ולכן מספר המילים גדול באחד ממספר הרווחים. תו בודד כותבים בין גרש לגרש: ' '.

static int CountWords(string str)
{
    if (str == "")
    {
        return 0;
    }
    int count = 0;
    for (int i = 0; i < str.Length; i++)
    {
        if (str[i] == ' ')
        {
            count++;
        }
    }
    return count + 1;
}

89מחרוזת פלינדרום

פלינדרום נקרא אותו דבר משני הכיוונים. משווים את הראשון לאחרון, את השני ללפני האחרון, וכן הלאה. שני משתנים זזים זה לקראת זה, עד שהם נפגשים.

static bool IsPalindrome(string str)
{
    int begin = 0;
    int end = str.Length - 1;
    while (begin < end)
    {
        if (str[begin] != str[end])
        {
            return false;
        }
        begin++;
        end--;
    }
    return true;
}

92איזו מחרוזת קודמת במילון

  • מספר חיובי: s1 באה אחרי.

98התווים המשותפים לשתי מחרוזות

עוברים על התווים של המחרוזת הראשונה. תו שנמצא גם בשנייה, ועוד לא נמצא בתוצאה, מוסיפים לתוצאה.

static string Intersection(string str1, string str2)
{
    string result = "";
    for (int i = 0; i < str1.Length; i++)
    {
        char ch = str1[i];
        if (str2.IndexOf(ch) != -1 && result.IndexOf(ch) == -1)
        {
            result += ch;
        }
    }
    return result;
}

Intersection("friendship", "wonderful")    →  frend
שימו לב: IndexOf שמחזירה -1 אומרת "לא נמצא". כך בודקים גם אם התו כבר בתוצאה, ולא מוסיפים אותו פעמיים.

99הרצף הארוך ביותר

מחפשים את הרצף הארוך ביותר של תווים זהים, זה אחרי זה. משווים כל תו לתו שלפניו: אם הם שווים הרצף ממשיך, ואחרת מתחיל רצף חדש. זה אותו רעיון של מציאת מקסימום מפרק 5.

static int LongestRun(string input)
{
    if (input == "")
    {
        return 0;
    }
    int max = 1;
    int current = 1;
    for (int i = 1; i < input.Length; i++)
    {
        if (input[i] == input[i - 1])
        {
            current++;
            if (current > max)
            {
                max = current;
            }
        }
        else
        {
            current = 1;
        }
    }
    return max;
}
פלט
LongestRun("LLOOOVVVVE")    →  4
LongestRun("inspiration")   →  1
LongestRun("")              →  0
שימו לב: הלולאה מתחילה ב-1 ולא ב-0, כי משווים כל תו לתו שלפניו.

100מיון מילים במשפט

מפרקים את המשפט למילים לפי הרווחים, וכל מילה מכניסים למקומה במשפט חדש שנשאר ממוין. העבודה מתחלקת בין שתי פעולות:

פעולהמה היא עושה
InsertInPlaceמקבלת משפט ממוין ומילה, ומחזירה משפט ממוין חדש שהמילה נמצאת בו במקומה
SortWordsעוברת על המילים של המשפט, ושולחת כל מילה ל-InsertInPlace
static string SortWords(string input)
{
    string sorted = "";
    if (input.Length == 0)
    {
        return sorted;
    }
    int spacePos = input.IndexOf(' ');
    while (spacePos != -1)
    {
        string word = input.Substring(0, spacePos);
        sorted = InsertInPlace(sorted, word);
        input = input.Substring(spacePos + 1);
        spacePos = input.IndexOf(' ');
    }
    sorted = InsertInPlace(sorted, input);
    return sorted;
}
