פרק 6: לולאת כל עוד

לולאת כל עוד (while) חוזרת על גוף הלולאה כל עוד התנאי אמת. היא מתאימה כשלא יודעים מראש כמה סיבובים יהיו, למשל כשקולטים עד שהמשתמש מקליד ערך מסוים, או כשעוברים על הספרות של מספר.

int num = 0;
while (num >= 0)
{
    num = int.Parse(Console.ReadLine());
}
forwhile

53קליטה עד שמוקלד מספר שלילי

לא יודעים מראש כמה מספרים המשתמשת תקליד, ולכן לולאת while מתאימה. המשתנה מקבל ערך התחלתי 0 כדי שהתנאי יהיה אמת בכניסה הראשונה. בתוך הלולאה סופרים רק את המספרים שאינם שליליים.

int num = 0, count = 0;
while (num >= 0)
{
    num = int.Parse(Console.ReadLine());
    if (num >= 0)
    {
        count++;
    }
}

54לולאת תקינות קלט

קולטים פעם אחת לפני הלולאה. כל עוד הקלט לא תקין, מבקשים שוב. התנאי של הלולאה הוא בדיוק התנאי לקלט שגוי.

num = int.Parse(Console.ReadLine());
while (num < 100 || num > 999)
{
    Console.Write("Not a 3 digit number. Try again: ");
    num = int.Parse(Console.ReadLine());
}
דוגמת הרצה
Enter a 3 digit number: 45
Not a 3 digit number. Try again: 1200
Not a 3 digit number. Try again: 347
Finally! The number is 347
שימו לב ל-||: מספר לא תקין הוא קטן מ-100 או גדול מ-999. עם && התנאי לעולם לא יתקיים, כי אין מספר שגם קטן מ-100 וגם גדול מ-999.

55ממוצע עד ערך עצירה

קולטים מספרים עד שמוקלד מינוס 1. ערך העצירה לא נכנס לחישוב, ולכן הסדר בלולאה חשוב: קודם מוסיפים לצובר, ורק בסוף הסיבוב קולטים את המספר הבא.

num = int.Parse(Console.ReadLine());
while (num != -1)
{
    sum += num;
    count++;
    num = int.Parse(Console.ReadLine());
}

56סכום הספרות של מספר

כל עוד נשארו ספרות במספר, לוקחים את ספרת האחדות, מוסיפים לסכום, ומוחקים אותה. מספר הסיבובים שווה למספר הספרות, ולא יודעים אותו מראש.

while (num > 0)
{

temp = num;

58הספרה השמאלית ומספר הספרות

כל עוד יש במספר יותר מספרה אחת (המספר גדול מ-9), מוחקים את ספרת האחדות. מה שנשאר בסוף הוא הספרה השמאלית. במקביל סופרים כמה ספרות נמחקו.

59הספרה הגדולה ביותר

זה אותו רעיון של מציאת מקסימום מפרק 5, רק על ספרות של מספר. מתחילים מספרת האחדות, מוחקים אותה, ומשווים כל ספרה שנשארה לגדולה ביותר.

maxDigit = num % 10;
num /= 10;
while (num > 0)
{
    currentDigit = num % 10;
    if (currentDigit > maxDigit)
    {
        maxDigit = currentDigit;
    }
    num /= 10;
}

61לולאה שרצה לפחות פעם אחת

בלולאת do-while התנאי נבדק בסוף, אחרי גוף הלולאה. לכן הגוף מתבצע תמיד לפחות פעם אחת. אין צורך לקלוט לפני הלולאה, ואין צורך לתת למשתנה ערך התחלתי מומצא.

do
{
    number = int.Parse(Console.ReadLine());
    if (number >= 0)
    {
        sum += number;
    }
} while (number >= 0);

64יציאה מהלולאה באמצע

התנאי while (true) תמיד אמת, ולכן הלולאה נראית אינסופית. הפקודה break מפסיקה את הלולאה מיד ויוצאת ממנה, גם באמצע הסיבוב.

while (true)
{
    answer = char.Parse(Console.ReadLine());
    if (answer == 'n' || answer == 'N')
    {
        break;
    }
    num = int.Parse(Console.ReadLine());
    sum += num;
}
