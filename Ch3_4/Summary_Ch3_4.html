פרק 3: הספרייה המתמטית ומחלקת אקראי

הספרייה המתמטית היא אוסף של פעולות מוכנות לחישובים. כל פעולה מקבלת ערכים בתוך סוגריים (פרמטרים) ומחזירה תוצאה. כותבים את שם הספרייה, נקודה, ואז את שם הפעולה: Math.Sqrt(16)

מחלקת אקראי מאפשרת להגריל מספרים. יוצרים עצם אחד מטיפוס Random, ומבקשים ממנו להגריל.

22חזקה

הפעולה Math.Pow(base, exponent) מקבלת בסיס ומעריך. הבסיס והמעריך יכולים להיות שלמים, עשרוניים או שליליים.

Math.Pow(2, 3)     // 8
Math.Pow(-2, 3)    // -8
Math.Pow(2, -1)    // 0.5
דוגמת הרצה
Enter the base: 2
Enter the exponent: 10
2 ^ 10 = 1024
שימו לב: הפעולה מחזירה תמיד double, גם כשהתוצאה היא מספר שלם. לכן השורה int x = Math.Pow(2, 3); לא תעבור קומפילציה. צריך משתנה עשרוני, או המרה מפורשת (int).

25הקטן והגדול מבין שלושה מספרים

Math.Min ו-Math.Max מקבלות שני מספרים בלבד. כדי להשוות שלושה מספרים, מפעילים את הפעולה פעמיים: התוצאה של הפעולה הפנימית נכנסת כפרמטר לפעולה החיצונית.

min = Math.Min(Math.Min(num1, num2), num3);
max = Math.Max(Math.Max(num1, num2), num3);

פרק 4: משפטי תנאי

משפט תנאי מאפשר לתוכנית לבחור מה לעשות, לפי הנתונים. עד עכשיו כל ההוראות בוצעו תמיד, אחת אחרי השנייה. מעכשיו חלק מההוראות יתבצעו רק במצבים מסוימים.

מבנהמתי משתמשים
ifמבצעים משהו רק אם התנאי מתקיים
if ... elseשתי אפשרויות, ותמיד מתבצעת אחת מהן
if ... else if ... elseכמה מקרים זרים, רק אחד מהם יכול לקרות
תנאי בתוך תנאישאלה שרלוונטית רק בתוך מקרה מסוים
switchמשתנה אחד מול כמה ערכים קבועים

כלל כתיבה: בכל הדוגמאות ההוראות שבתוך התנאי עטופות בסוגריים מסולסלים { }, גם כשיש רק הוראה אחת, ומוזזות פנימה בטאב אחד (הזחה). כך רואים בבירור מה שייך לתנאי.
