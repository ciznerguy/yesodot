1סוגי משתנים והגדרתם

משתנה הוא מקום בזיכרון שבו שומרים נתון. בהגדרה כותבים קודם את הטיפוס ואחריו את שם המשתנה, ואפשר לתת לו ערך כבר בהגדרה.

טיפוסמה הוא מכילגודל בזיכרוןדוגמאות לערכים
intמספר שלם, חיובי או שלילי4 בתים32, 0, -7
doubleמספר עשרוני (ממשי)8 בתים87.5, -2.25
charתו אחד, בין גרשיים בודדים2 בתים'A', '7', '!'
boolאמת או שקר בלבדבית אחדtrue, false
stringטקסט באורך כלשהו, בין גרשיים כפוליםלפי האורך"Hello"
כללים לשמות משתנים
  • מותר להשתמש באותיות, ספרות וקו תחתון בלבד.
  • אסור רווחים, ואסור להתחיל בספרה.
  • יש הבדל בין אותיות גדולות לקטנות: sum ו-Sum הם שני משתנים שונים.
  • נותנים שם משמעותי, וכל מילה חדשה בשם מתחילה באות גדולה: numOfStudents

3קליטת מחרוזת מהמשתמש

הפקודה Console.ReadLine() מחכה שהמשתמש יקליד טקסט ויקיש Enter, ומחזירה את מה שהוקלד. שומרים את הערך במשתנה מטיפוס string.

name = Console.ReadLine();
Console.WriteLine("Hello " + name + "!");

הסימן + בין מחרוזות מחבר אותן לטקסט אחד. לפעולה הזו קוראים שרשור.

דוגמת הרצה (הקלט מודגש)
Enter your name: Dana
Hello Dana!

5אתחול והשמה

בהשמה המחשב מחשב קודם את הביטוי שבצד ימין של הסימן =, ורק אחר כך שם את התוצאה במשתנה שבצד שמאל.

int x, y, z = 9;
x = 5;
y = x * 3;
x = x + 1;
פלט
x = 5, y = 15, z = 9
x after x = x + 1 is 6
שימו לב: השורה x = x + 1 היא לא משוואה. היא אומרת: קחי את הערך של x, הוסיפי לו 1, ושימי את התוצאה בחזרה ב-x. שימוש במשתנה שעוד לא קיבל ערך גורם לשגיאת קומפילציה.

9ממוצע של שני ציונים

  • קלט: שם של תלמידה ושני ציונים.
  • חישוב: הממוצע נשמר במשתנה average מטיפוס double.
  • פלט: השם והממוצע.
average = (grade1 + grade2) / 2;
דוגמת הרצה
Enter the student's name: Noa
Enter the first grade: 85
Enter the second grade: 90
The average of Noa is 87
מלכודת: הממוצע האמיתי הוא 87.5, אבל הודפס 87. שני הציונים שלמים וגם 2 הוא מספר שלם, ולכן זו חלוקת שלמים והחלק העשרוני נחתך. זה קורה עוד לפני שהתוצאה נכנסת למשתנה העשרוני. כדי לקבל תוצאה מדויקת מחלקים במספר עשרוני: 
average = (grade1 + grade2) / 2.0;

isEven = num % 2 == 0;

17הגדלה והקטנה באחד

שלוש השורות האלה מגדילות את x ב-1: x = x + 1; x++; ++x;

ההבדל מופיע כשמשתמשים באופרטור בתוך השמה:

קוד (x מתחיל ב-4)תוצאההסבר
y = x++;x = 5, y = 4קודם y מקבל את הערך הישן, אחר כך x גדל
y = ++x;x = 5, y = 5קודם x גדל, אחר כך y מקבל את הערך החדש
y = x--;x = 3, y = 4קודם y מקבל את הערך הישן, אחר כך x קטן
y = --x;x = 3, y = 3קודם x קטן, אחר כך y מקבל את הערך החדש

18אופרטורים מקוצרים

כתיבה מקוצרתכתיבה מלאהx אחרי הפעולה
x += 5;x = x + 5;15
x -= 3;x = x - 3;12
x *= 2;x = x * 2;24
x /= 4;x = x / 4;6
x %= 4;x = x % 4;2
שימו לב: הביטוי שמימין מחושב קודם, כאילו הוא בסוגריים. כש-x שווה 3 ו-y שווה 2, הפעולה x *= y + 1; נותנת 9, כי היא בעצם x = x * (y + 1);

19המרות בין טיפוסים

  • בביטוי עם int ו-double, המספר השלם מומר אוטומטית לעשרוני, רק לצורך החישוב.

  • להמרה מפורשת כמו (double) יש קדימות גבוהה, ולכן היא מתבצעת לפני החילוק.
