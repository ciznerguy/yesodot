פרק 7: פעולות

פעולה היא אוסף הוראות שקיבל שם. כותבים אותה פעם אחת, וקוראים לה בכל מקום שצריך. כשקוראים לפעולה, התוכנית קופצת אליה, מבצעת את ההוראות, וחוזרת לשורה שאחרי הקריאה.

static int Max(int n1, int n2, int n3)
{
    ...
    return max;
}
חלק בכותרתבדוגמהמשמעות
סוג הערך המוחזרintמה הפעולה מחזירה. void אם היא לא מחזירה כלום
שם הפעולהMaxשם משמעותי שמתאר מה הפעולה עושה

66למה צריך פעולות: ציור ריבועים

בלי פעולות, כדי לצייר שני ריבועים בגדלים שונים היינו כותבים את אותן לולאות פעמיים. עם פעולות כותבים את הקוד פעם אחת, וקוראים לו עם גדלים שונים.

static void PrintLine(int length)
{
    for (int i = 1; i <= length; i++)
    {
        Console.Write("*");
    }
    Console.WriteLine();
}

static void DrawSquare(int size)
{
    for (int i = 1; i <= size; i++)
    {
        PrintLine(size);
    }
}

67פעולות מוכנות כקופסה שחורה

כבר השתמשנו בהרבה פעולות שמישהו אחר כתב: Console.WriteLine, int.Parse, Math.Sqrt. לא צריך לדעת איך הן כתובות מבפנים. מספיק לדעת מה הן מקבלות ומה הן מחזירות, ולכן קוראים להן קופסה שחורה.

double root = Math.Sqrt(81);
int bigger = Math.Max(17, 42);
int number = int.Parse("123");
פלט
Square root of 81: 9
The bigger of 17 and 42: 42
The text 123 as a number, plus 1: 124
שם המחלקה: כשקוראים לפעולה ממחלקה אחרת, כותבים את שם המחלקה, נקודה, ושם הפעולה. לפעולה שכתבנו באותה מחלקה קוראים בשם בלבד.

68טווח ההכרה של משתנים

משתנה שהוגדר בתוך פעולה מוכר רק בתוכה. אם בשתי פעולות יש משתנה עם אותו שם, אלה שני משתנים שונים לגמרי.

public static void example68()
{
    int num = 7;
    ShowOtherNum();
    Console.WriteLine(num);   // 7
}

static void ShowOtherNum()
{
    int num = 99;
    Console.WriteLine(num);   // 99
}
פלט
In the example, num = 7
In the other method, num = 99
Back in the example, num = 7
שימו לב: גם משתנה הבקרה של לולאה, כמו i, מוכר רק בתוך הלולאה. לכן אפשר להשתמש בשם i שוב בלולאה אחרת.

70פעולה שמקבלת כמה פרמטרים

הפרמטרים מופרדים בפסיק, ולכל אחד יש טיפוס משלו. בקריאה שולחים ערכים באותו מספר, באותו סדר ומאותו טיפוס. הערך הראשון נכנס לפרמטר הראשון, והשני לשני.

static void PrintAverage(int n1, int n2)
{
    double average = (n1 + n2) / 2.0;
    Console.WriteLine("The average of " + n1 + " and " + n2 + " is " + average);
}
דוגמת הרצה (הקלט מודגש)
Enter the first grade: 85
Enter the second grade: 90
The average of 85 and 90 is 87.5
The average of 80 and 95 is 87.5

72פעולה שמחזירה ערך

פעולה יכולה לחשב ערך ולהחזיר אותו למי שקרא לה. בכותרת כותבים את הטיפוס של הערך המוחזר, ובסוף הפעולה return. את הערך אפשר לשמור במשתנה, להדפיס, או להשתמש בו בתוך ביטוי.

73האם המספר פלינדרום

פלינדרום הוא מספר שנקרא אותו דבר משני הכיוונים, למשל 91819. פעולה אחת מחזירה את המספר ההפוך, כמו בפרק 6. הפעולה השנייה משתמשת בה.

static bool IsPalindrome(int num)
{
    return num == Reverse(num);
}

הפעולה מחזירה bool, ולכן אפשר לקרוא לה ישר בתוך תנאי: if (IsPalindrome(num)) או while (!IsPalindrome(num)).

75כמה פעמים ספרה מופיעה במספר

הפעולה מקבלת מספר וספרה, ועוברת על הספרות בלולאת while, כמו בפרק 6. בכל פעם שספרת האחדות שווה לספרה המבוקשת, המונה גדל.

static int CountDigit(int number, int digit)
{
    int count = 0;
    while (number > 0)
    {
        if (number % 10 == digit)
        {
            count++;
        }
        number /= 10;
    }
    return count;
}
דוגמת הרצה

Enter a number: 1223
Enter a digit: 2
2 appears in 1223 2 times
מקרה קצה: עבור המספר 0 הלולאה לא מתבצעת אפילו פעם אחת, ולכן הפעולה מחזירה 0 גם כשמחפשים את הספרה 0.

76העמסת פעולות

אפשר לכתוב כמה פעולות עם אותו שם, בתנאי שהפרמטרים שלהן שונים: במספר או בטיפוס. לפי הערכים ששולחים, המחשב יודע לאיזו פעולה לקרוא.

כותרתקריאהתוצאה
int Min(int x, int y)Min(1, 2)1
int Min(int x, int y, int z)Min(4, 3, 2)2
double Min(double x, double y)Min(1.3, 2.7)1.3
מה אסור: שתי פעולות עם אותו שם ואותם טיפוסי פרמטרים, גם אם שמות הפרמטרים שונים. למשל Min(int x, int y) ו-Min(int a, int b) הן אותה חתימה, וזו שגיאת קומפילציה.

77מרחק בין שתי נקודות

תכנון מלמעלה למטה: מתחילים מהפעולה הגדולה, ומפרקים אותה לפעולות עזר קטנות. המרחק הוא שורש של סכום ריבועי ההפרשים. לחזקה כתבנו פעולה משלנו, ולשורש השתמשנו בפעולה המוכנה.

static double Distance(int x1, int y1, int x2, int y2)
{
    double sum = Power(x2 - x1, 2) + Power(y2 - y1, 2);
    return Math.Sqrt(sum);
}
